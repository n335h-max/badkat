# Changelog

## 0.2.0 - 2026-09-21

### Added
- Optional daily foreground-time allowance and weekly patrol schedule.
- Keyboard-accessible Snooze and Pat actions, improved settings navigation, and reduced-motion support.
- Windows CI checks and downloadable test installers; draft-first verification for signed releases.

### Fixed
- Close XP is awarded only after the original target is confirmed closed or no longer matches.
- Invalid settings are rejected before changing live or saved configuration.
- Configuration and progress saves are recoverable after interrupted writes.
